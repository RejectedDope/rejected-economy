# ResaleIQ Knowledge Library

ResaleIQ should not use one giant undifferentiated document dump. Keep durable knowledge separate from live market evidence.

## Durable knowledge collections

### Marketplace playbooks
Maintain one file per marketplace:
- eBay
- Poshmark
- Mercari
- Vinted
- Facebook Marketplace
- Depop
- Whatnot
- Etsy
- Grailed
- Vestiaire Collective

Each playbook should contain only durable strategy and terminology. Current fees, policies, restricted-item rules, and feature availability should be verified live before use.

### Category intelligence
Maintain playbooks for:
- Handbags and luxury
- Vintage clothing
- Shoes
- Jewelry
- Toys and collectibles
- Electronics
- Home and MCM
- Media
- Miscellaneous hard goods

Each category file should cover identification signals, high-value markings, condition issues that materially change value, measurements buyers expect, common search terminology, shipping risks, and authentication boundaries.

### Resale language dictionary
Store standardized, defensible terminology for apparel construction, fashion aesthetics, handbag forms, jewelry construction, vintage dating clues, toys, collectibles, electronics, and home goods.

Aesthetic labels must never be added merely because they are popular search terms. Use only when visually supported.

### Condition and defect library
Document objective condition language by category and examples of defects that must be disclosed.

### Photo requirements by category
Define the minimum useful photo set for each category. The agent should request another photo only when the missing view can materially affect identification, value, authenticity risk, or listing accuracy.

### Shipping decision guide
Keep durable packaging and risk principles here. Verify current carrier rates and marketplace-specific shipping rules live.

### Restricted and high-risk items
Maintain category warning signs, but verify current marketplace rules before advising a sale.

## Dynamic evidence

Do not place rapidly changing market data into static knowledge files as permanent truth.

Store dynamic evidence in the Resale Evidence Graph:
- exact sold comps
- near-exact sold comps
- active comps
- official product records
- policy snapshots
- community signals
- seller observations

Every evidence record should retain source, timestamp, external ID when available, URL when available, and original payload.

## Community intelligence rules

Facebook groups, Reddit, reseller forums, YouTube, TikTok, Discord, blogs, and newsletters are useful signal sources but not authoritative market truth.

Community signals should be stored as `community_signal` evidence and treated as unverified until corroborated when the claim materially affects price, safety, marketplace policy, or authenticity.

Useful community signals include:
- emerging buyer language
- unusual sourcing opportunities
- sudden category interest
- marketplace operational problems
- practical seller workarounds that comply with platform rules
- new scam patterns
- collector terminology

Never turn repetition into certainty. Ten people repeating the same unsupported claim is still an unsupported claim.

## Rejected Treasures proprietary learning loop

The strongest long-term data source is the seller's own result history.

For every item, retain:
1. identity hypotheses and evidence
2. acquisition cost
3. pricing recommendation
4. chosen marketplace
5. listing title and price history
6. engagement metrics when available
7. offers received
8. final sale price
9. marketplace fees
10. shipping and packaging costs
11. actual net proceeds
12. days to sale

This supports future questions such as:
- Which brands actually produce the most net profit?
- Which categories tie up cash too long?
- What does the seller repeatedly overpay for?
- Which marketplace performs best for specific inventory?
- Which stale listings should move platforms rather than receive another markdown?
- Which items should be listed first from a death pile?

## Maintenance rule

Static knowledge explains how to think. Live tools provide current facts. Proprietary sales history teaches what works for this seller.
